## Теоретическое обоснование
Бэкенд (backend) — это серверная часть веб-приложения, которая отвечает за обработку запросов от клиентов, взаимодействие с базами данных, выполнение бизнес-логики и формирование ответов. Бэкенд работает на сервере и не виден пользователю напрямую.

<a id="контрольные-вопросы"></a>
## Контрольные вопросы

**1. Что такое клиент-серверная архитектура?**
Это модель взаимодействия в компьютерных системах, при которой задачи распределены между двумя ключевыми компонентами: клиентом и сервером.

**2. Какой протокол используется для общения клиента и сервера в вебе?**
Для общения клиента и сервера в вебе используется протокол HTTP.

**3. Что такое эндпоинт?**
Это точка доступа, через которую клиентское приложение взаимодействует с сервером или сервисом для выполнения операций или получения данных.

**4. Какую структуру имеет HTTP-запрос и HTTP-ответ? Что такое код состояния?**
HTTP-запрос состоит из стартовой строки (метод, URI, версия), заголовков и опционального тела. HTTP-ответ состоит из стартовой строки (версия, код состояния, пояснение), заголовков и опционального тела. Код состояния — трёхзначное число в ответе сервера, показывающее результат обработки запроса (например, 200 — успех, 404 — не найдено).

**5. Что такое JSON? Почему он популярен?**
JSON — текстовый формат обмена данными на основе пар ключ-значение и массивов. Популярен потому, что он лёгкий, читаемый человеком, легко парсится и генерируется, не зависит от языка и удобен для передачи данных в веб-API.

**6. Как запустить сервер на Node.js?**
Создать файл (например, server.js), подключить модуль http через require('http'), вызвать http.createServer() с обработчиком запросов, затем server.listen(порт, callback). Запустить командой node server.js.

**7. Что такое автоматический перезапуск и зачем он нужен? Какой пакет используется в Node.js?**
Автоматический перезапуск — это автоматическое перезапускание сервера при изменении файлов кода, без ручной остановки и запуска. Нужен для удобства разработки и экономии времени. В Node.js для этого используется пакет nodemon.

**8. Какие коды состояния HTTP вы знаете? За что отвечает код 404?**
Основные группы: 1xx — информационные, 2xx — успех (200 OK, 201 Created), 3xx — перенаправления (301, 302), 4xx — ошибки клиента (400, 401, 403, 404), 5xx — ошибки сервера (500, 502, 503). Код 404 означает, что запрошенный ресурс не найден на сервере.

**9. Что такое middleware в Express?**
Middleware в Express — это функции с доступом к объектам запроса (req), ответа (res) и функции next, которые выполняются последовательно в цепочке обработки запроса. Они могут изменять запрос/ответ, завершать обработку или передавать управление дальше через next(). Используются для логирования, аутентификации, парсинга тела запроса и т.д.

**10. Как получить параметр из URL-пути (например, ID) в Express?**
Через параметры маршрута: в пути указывается двоеточие, например app.get('/users/:id', ...), а значение доступно в req.params.id.

## Код сервера
```javascript
const express = require('express');
const app = express();
const port = 3000;

app.use((req, res, next) => {
    console.log(`[${new Date().toISOString()}] ${req.method} ${req.url}`);
    next(); 
});


app.get('/', (req, res) => {
    res.send('Добро пожаловать на сервер!');
});


app.get('/api/posts', (req, res) => {
    const posts = [
        { id: 1, title: 'Первый пост', content: 'Содержимое первого поста' },
        { id: 2, title: 'Второй пост', content: 'Содержимое второго поста' },
        { id: 3, title: 'Третий пост', content: 'Содержимое третьего поста' }
    ];
    res.json(posts);
});

app.get('/api/comments', (req, res) => {
    const comments = [
        { id: 1, postId: 1, text: 'Комментарий к первому посту' },
        { id: 2, postId: 2, text: 'Комментарий ко второму посту' },
        { id: 3, postId: 1, text: 'Ещё один комментарий к первому посту' }
    ];
    res.json(comments);
});


app.get('/api/posts/:id', (req, res) => {
    const postId = parseInt(req.params.id, 10);
    const posts = [
        { id: 1, title: 'Первый пост', content: 'Содержимое первого поста' },
        { id: 2, title: 'Второй пост', content: 'Содержимое второго поста' },
        { id: 3, title: 'Третий пост', content: 'Содержимое третьего поста' }
    ];
    const post = posts.find(p => p.id === postId);
    if (post) {
        res.json(post);
    } else {
        res.status(404).json({ error: 'Пост не найден' });
    }
});

app.use((req, res) => {
    res.status(404).json({ error: 'Маршрут не найден' });
});


app.listen(port, () => {
    console.log(`Сервер запущен на http://localhost:${port}`);
});
```
